# Contributing to Cerbero-Scanner

¡Gracias por tu interés en contribuir a Cerbero-Scanner! 🎉

Este proyecto es Open Source y cualquier ayuda es bienvenida, ya sea reportando bugs, mejorando la documentación o escribiendo código.

## 🐛 Reportando Bugs

Si encuentras un error, por favor abre un **Issue** en GitHub incluyendo:
1.  Descripción del error.
2.  Pasos para reproducirlo.
3.  Logs o capturas de pantalla (¡Cuidado con no subir credenciales!).

## 💡 Sugiriendo Mejoras

¿Tienes una idea genial? Abre un Issue con la etiqueta `enhancement` y cuéntanos de qué se trata.

## 💻 Desarrollo

1.  Haz un **Fork** del repositorio.
2.  Crea una rama para tu feature (`git checkout -b feature/nueva-funcionalidad`).
3.  Instala las dependencias de desarrollo:
    ```bash
    pip install -r requirements.txt
    ```
4.  Asegúrate de que tu código sigue el estilo del proyecto.
5.  Haz **Commit** de tus cambios (`git commit -m 'Add: Nueva funcionalidad'`).
6.  Haz **Push** a tu rama (`git push origin feature/nueva-funcionalidad`).
7.  Abre un **Pull Request**.

## 🧪 Tests

Por favor, asegúrate de que los tests pasen antes de enviar tu PR:
```bash
pytest
```

¡Gracias por ayudar a hacer de Cerbero-Scanner una herramienta mejor! 🛡️
